# Answer library

This is where the company's approved proposal content lives. The skill only states facts it finds here,
so the quality of every proposal depends on this folder.

Format: see `../references/library-format.md`. Each `.md` file holds entries like:

```markdown
## ANS-SEC-001: Encryption of data at rest and in transit
tags: security, encryption, tls, gdpr
last_reviewed: 2026-05-14
owner: Security lead
approved_for: external

Approved answer text…
```

## What to collect first (highest value)

| Folder | Content | Typical owner |
|---|---|---|
| `company/` | Profile, size, locations, turnover, certifications (with expiry), insurance, policies | CEO / Finance / Quality |
| `answers/` | Standard answers: security, GDPR, delivery method, QA, support SLA, accessibility, DevOps, HR (background checks, retention) | Security lead, Delivery head |
| `case-studies/` | One entry per project: client, sector, problem, solution, numeric results, period, tech, referenceable yes/no | Account managers |
| `team/` | CV summaries of key roles (anonymized or named) | Resource manager |
| `pricing/` | Rate card, pricing models, discount approval rules | Finance / Sales head |
| `boilerplate/` | About us, closing statement, standard assumptions and disclaimers | Marketing |

Harvest answers from the last 5–10 proposals (winning ones first). That is the fastest way to fill this library.
